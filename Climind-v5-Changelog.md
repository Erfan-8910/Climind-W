## 🚀 Installation & Deployment

### Option 1: One-Click Smart Script (Recommended)

```bash
# Download install.sh, make it executable, and run:
chmod +x install.sh
./install.sh
```

**What the script does:**
- ✅ Auto-detects `python3` / `python` / `node`
- ✅ **Fresh Install** — Downloads `index.html` from GitHub if not present
- ✅ **Already Installed?** Choose: `[S]tart` · `[U]pdate` · `[R]emove` · `[Q]uit`
- ✅ **Update** — Pulls the latest `index.html` directly from the repo
- ✅ **Remove** — Safely uninstalls after confirmation
- ✅ Auto-finds a free port (8080+)
- ✅ Launches server and prints the URL

> **Tip:** You can change the install directory with the `CLIMIND_DIR` environment variable:
> ```bash
> CLIMIND_DIR=/opt/climind ./install.sh
> ```

### Option 2: Manual — Python

```bash
cd /path/to/climind
python3 -m http.server 8080
# Open http://localhost:8080
```

### Option 3: Manual — Node.js

```bash
cd /path/to/climind
npx serve -l 8080
# Open http://localhost:8080
```

### Option 4: Deploy to Cloudflare Pages (Free)

```bash
# 1. Fork the repo
# 2. Connect to Cloudflare Pages
# 3. Build command: (none)
# 4. Output directory: /
# Done! Your app is live globally.
```

### Option 5: Deploy to GitHub Pages (Free)

```bash
# 1. Push index.html to your repo
# 2. Go to Settings → Pages
# 3. Source: Deploy from a branch → main → / (root)
# 4. Your app goes live at https://yourname.github.io/repo-name
```

### Option 6: Deploy to Vercel / Netlify (Drag & Drop)

```bash
# 1. Go to vercel.com or netlify.com
# 2. Drag & drop your project folder
# 3. Get a live URL in 30 seconds
```
